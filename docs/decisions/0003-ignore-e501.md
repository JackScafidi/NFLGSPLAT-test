# 0003: Ignore ruff's line-length rule (E501)

## Context

CI runs `ruff check nfl_gsplat tests scripts` with rules E and F and
`line-length = 110`. On 2026-11-24 it failed on 2239 findings, 2201 of them
lines over 110 characters, in 139 files. Most are code with aligned trailing
comments. `ruff format` would rewrite 455 files and still leave 875 long lines.

## Decision

Add `E501` to `ignore` in `pyproject.toml`. Keep `line-length = 110` as the
guide for new code. Don't adopt `ruff format` for now. The other 38 findings
were fixed by hand.

## Consequences

- CI's lint job passes again, and every other E and F rule stays enforced.
- Long lines are a matter of review, not of CI.
